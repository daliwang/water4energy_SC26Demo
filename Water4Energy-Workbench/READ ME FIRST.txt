Water4Energy workbench v0.15.1 — public interface source

Open the Water4Energy-Workbench folder and double-click Start TVA Workbench.command.
Keep Terminal open and follow the printed local URL. Python 3.9+ is required.

This checkout opens the interface without changing the local VISTA backend.
For live chat, open VISTA, configure your own model provider, and connect to
Water4Energy-TVA-agent-loop in Connection settings.

The complete Mac package is in ../packages/v0.15.1/.
Download Water4Energy-Workbench-v0.15.1-All-in-One-Mac.zip and extract it.
Open TVA-Workbench and use its Start TVA Workbench.command launcher for
the interface plus VISTA backend setup; no separate setup bundle is needed.

See README.md and VISTA_SETUP.md for details.
